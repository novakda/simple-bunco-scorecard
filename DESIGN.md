# Design System — Simple Bunco Scorecard

Generated by `/plan-design-review` on 2026-04-28. Source of truth for visual decisions.

## Color Tokens

```css
:root {
  --bg:         #0f0f0f;   /* near-black background */
  --surface:    #1c1c1c;   /* card / button surface */
  --surface-hi: #2a2a2a;   /* button hover / pressed state */
  --accent:     #f59e0b;   /* amber — primary accent, BUNCO! button */
  --accent-dim: #92400e;   /* dimmed accent for secondary elements */
  --text-hi:    #f5f5f5;   /* primary text */
  --text-mid:   #a3a3a3;   /* secondary labels */
  --text-lo:    #525252;   /* muted / disabled text */
  --win:        #22c55e;   /* W badge */
  --loss:       #ef4444;   /* L badge */
  --tie:        #6b7280;   /* T badge */
}
```

Contrast: `--text-hi` on `--bg` = 17.4:1 (WCAG AAA). `--accent` on `--bg` = 8.7:1 (WCAG AA).

## Typography

- **Oswald Bold 700** (Google Fonts) — hero numbers, BUNCO! button label
- **Inter Regular 400 + SemiBold 600** (Google Fonts) — all body text, labels, history

```css
@import url('https://fonts.googleapis.com/css2?family=Oswald:wght@700&family=Inter:wght@400;600&display=swap');

.font-display { font-family: 'Oswald', 'Impact', sans-serif; font-weight: 700; }
.font-body    { font-family: 'Inter', 'Helvetica Neue', sans-serif; }
```

## Score Entry Button Layout

```
[ 0  ] [ 1  ]      ← 2-col grid, 64px height each
[ 2  ] [ 3  ]
[ BUNCO! — full width, 80px, --accent fill ]
[ MINI-BUNCO — full width, 56px, --accent-dim fill ]
```

CSS approach: CSS custom properties only. No Tailwind. No component library.

## Component Patterns

### GameContext (hero region)
- Target number: large Oswald number, centered, color `--accent`
- "Rolling for X" context line: Inter 14px, color `--text-mid`
- Round points + "N to win": Oswald 36px, color `--text-hi`
- Set / Round: Inter 14px, color `--text-lo`, positioned as sub-labels

### ScoreEntry
- Buttons: `background: --surface`, `color: --text-hi`, `border-radius: 12px`
- BUNCO! button: `background: --accent`, `color: --bg` (dark text on amber)
- MINI-BUNCO button: `background: --accent-dim`, `color: --text-hi`
- Disabled state (phase !== 'playing'): `opacity: 0.35`, `pointer-events: none`

### RoundHistory
- Fixed height: ~80px, overflow-y: auto
- Each row: round number + points + W/L/T badge
- Badge colors: `--win` / `--loss` / `--tie`

### BUNCO! Celebration Screen
Full-screen takeover when `phase === 'round-end' && lastRoll.type === 'bunco'`:
- Background: `--accent` or radial gradient amber → `--bg`
- Text: "BUNCO!" in Oswald 700, 96px+, color `--bg` (dark on amber)
- Animation: CSS `@keyframes` pulse/scale entrance
- Haptic: `navigator.vibrate(200)` on tap (Android; no-op elsewhere)
- Auto-advance: `commitRound('W')` after 2000ms; tap anywhere to advance early

### W/L/T Picker
Three large separate buttons when `phase === 'round-end' && lastRoll.type !== 'bunco'`:
- Layout: flex row, each button 1/3 width, 64px height
- Tap immediately calls `commitRound(result)` — no confirm step

### Phase Transition Screens
- **set-end:** Full-page replacement, shows set summary
- **game-over:** Full-page replacement; use `--accent` border/accent line for more weight

### Empty State (first open)
App opens directly in `phase='playing'`, set 1, round 1.
On first open (detect via `bunco-first-seen` localStorage key):
- Show dismissable hint bar: "Tap 0–3 to record your score. Tap BUNCO! for a Bunco."
- Dismiss on first any-tap. Never shown again.
